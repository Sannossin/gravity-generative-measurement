**Specific or shared?** Only one prediction is specific to the framework: the full dark-energy curve with no free parameter (bet μ0 = 4/3). The point (n_s, r) is shared by any Starobinsky model with the same reheating; the absence of entanglement is shared by classical-gravity models; the (w0, wa) position lies close to the "mirage" line common to many models.
